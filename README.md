# Welcome Web Project

A tiny starter project that opens a welcome page in the browser.

## Prerequisites

- Node.js 18+ (recommended)

## Run

1. Open terminal in this folder
2. Run:

```bash
npm start
```

3. Open:

http://127.0.0.1:5500

## Files

- `index.html` - page structure
- `styles.css` - page styling and animation
- `script.js` - simple button interaction
